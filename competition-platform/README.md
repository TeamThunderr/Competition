# College Competition Management Platform

## Overview
A simple, beginner-friendly platform to manage college competitions.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: Supabase

## Setup
1. Go to `backend/` and run `npm install` then `npm start`.
2. Go to `frontend/` and run `npm install` then `npm run dev`.

## Documentation
See `docs/` folder for API and Flow documentation.
